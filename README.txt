Link to PDF
===========
Paste a web link, get a PDF you can print, keep or send.

To put this online, see the install instructions.
Everything needed is in this folder. Do not rename the folders.

  Dockerfile          tells the server how to set itself up
  requirements.txt    the parts it needs
  render.yaml         settings for the hosting service
  app/main.py         the engine that makes the PDFs
  app/static/         the web page people see
